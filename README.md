# Transol Transportation Website

## Overview
Transol Transportation Website is a digital hub for mobility where passengers can access real-time bus schedules and routes, purchase and recharge transport cards online, and see all registered bus stops and nearest pick-up points. The platform is designed to be simple, reliable, and professional, positioning Transol as a smart mobility solution for cities and communities.

## Features

### Real-time Bus Schedules and Routes
- Interactive route map
- Searchable route database
- Detailed schedule information
- Route details with stops and timing

### Transport Card Management
- Online purchase of different card types
- Card recharge functionality
- Detailed card information and benefits
- Secure payment processing

### Bus Stop Locator
- Interactive map of all bus stops
- Search functionality for finding stops
- Detailed stop information including amenities
- Directions to nearest stops

## Project Structure

```
transol-website/
├── css/
│   ├── styles.css       # Main stylesheet
│   └── modal.css        # Modal component styles
├── js/
│   ├── main.js          # Core JavaScript functionality
│   └── data-loader.js   # Data loading and display logic
```
